# Hackathon
SAS 26-27 Hackathon - Sid Razdan

Singapore imports %90 of its food, throwing away nearly a third of what it imports. Overall, Singapore generates roughly 784,000 tonnes of food waste a year - only 18% of which gets recycled, with the rest filling up Semakau Landfill. 

Hawker centres and other restaurants around Singapore generate daily food surplus and scraps, but our community currently lacks a public digital system to connect that surplus to either redistribution (giving food that is still edible to charities) or composting (for scraps that are inedible). Existing tools like Too Good To Go and Treatsure are simply static directories that lack the live-updating tools required to help. 

Surplus-to-Soil is an open-ended, two-sided matching tool aiming to repurpose food that would otherwise be wasted. It allows edible food to go to charities and those in need, and only aims to compost when that is unavailable. This is done in the form:
  1. A hawker stall/centre posts about surplus food, clarifying: type, quantity, and whether it's edible or scraps
  2. The system automatically routes the post to the appropriate page: still edible -> charities feed or scraps only -> gardens feed.
  3. A running impact dashboard is set up to post kg posted, kg claimed, and estimated savings and impact.
